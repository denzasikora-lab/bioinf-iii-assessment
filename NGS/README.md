# NGS: HBB человека

Готовый отчет: [HBB_sequence_report.pdf](HBB_sequence_report.pdf).

В индивидуальном архиве [A114.fasta.gz](input/A114.fasta.gz) находится одна белковая последовательность длиной 147 аминокислот. Она полностью совпадает с [UniProtKB P68871](https://www.uniprot.org/uniprotkb/P68871/entry), HBB_HUMAN - бета-цепью гемоглобина, ген HBB. Организм Homo sapiens указан по аннотации записи.

Лабораторный журнал содержит команды, контрольные суммы, проверку аннотации в UniProtKB и NCBI Gene, локальное сравнение с эталоном, ограничения вывода и цитату Abstract статьи с DOI [10.1016/j.retram.2025.103513](https://doi.org/10.1016/j.retram.2025.103513).

Из корня репозитория, Python 3.9 или новее:

```bash
python3 NGS/verify_sequence.py
```

Ожидается 147/147 совпадений, без замен и разрывов. Скрипт использует стандартную библиотеку Python и [локальный эталон](reference/P68871.fasta), скачанный 05.09.2026 с https://rest.uniprot.org/uniprotkb/P68871.fasta. Исходная последовательность для этой проверки в веб-сервисы не отправляется.

Исходная формулировка задания сохранена в [docs/assignment_ngs.md](../docs/assignment_ngs.md). Повторный запрос архива на сервере для воспроизведения не требуется.
