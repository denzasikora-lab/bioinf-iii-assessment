# BIOINF III Assessment (NGS)

**Итоговый отчёт оформляется в виде PDF-файла и прикладывается в репозиторий**

Тема задания: описание генетической последовательности.

* Зайдите на сервер, используя информацию из письма, полученного после регистрации на странице программы: https://bioinf.me/education/bioinf_iii_step
* Скачайте с сервера FASTA-файл с информацией о гене:
  *  Подключитесь к серверу: ssh -p 8126 <login>@smp4.icgbio.ru
  *  Запустите bioinf3-testtask (введите bioinf3-testtask в командной строке после входа);
  *  Введите имя, фамилию и GitHub Username;
  *  Вы получите архив с заданием.
* Определите, какой ген представлен в файле, и, если это возможно, модельный организм, которому он принадлежит.
* Оформите весь процесс поиска и определения в виде лабораторного журнала: фиксируйте использованные инструменты, запросы, промежуточные результаты и ваши рассуждения на каждом шаге.
* Дополните лабораторный журнал записью: укажите DOI какой-либо одной статьи, релевантной исследованиям данного гена/белка и организма, и приведите одно-два предложения из раздела "Abstract" этой статьи, которые считаете ключевыми для краткого представления исследования.
* Оформите получившийся отчёт в виде PDF-файла и приложите его в репозиторий.

Работа должна быть воспроизводимой: по вашему лабораторному журналу должно быть понятно, как именно вы пришли к результату — какие инструменты и базы данных использовали и почему.

Объем отчета не регламентирован, главное — необходимое и достаточное описание хода ваших рассуждений.
