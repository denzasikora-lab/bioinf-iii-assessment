# BIOINF III Assessment (NGS)

English translation of the supplied assessment instructions.

The final report must be a PDF file included in the repository.

Task: describe a genetic sequence.

* Log in to the server using the information in the email received after registration on the [program page](https://bioinf.me/education/bioinf_iii_step).
* Download the FASTA file containing the gene information:
  * Connect with `ssh -p 8126 <login>@smp4.icgbio.ru`.
  * Run `bioinf3-testtask` after logging in.
  * Enter your first name, last name, and Stepik ID exactly as provided in the application form.
  * You will receive an assessment archive.
  * Other applicants' archives are on the same server. Download your own archive; every task is individual.
  * Request the task only once. Although a second request is technically possible, it leads to disqualification.
  * Leave the server after receiving the task. Complete the analysis only on resources personally available to you, since other applicants could otherwise compromise your work and pipelines.
* Identify the gene in the file and, if possible, the model organism to which it belongs.
* Document the complete search and identification process as a laboratory notebook: record tools, queries, intermediate results, and reasoning at every step.
* Add the DOI of one article relevant to this gene/protein and organism. Quote one or two sentences from its Abstract that you consider central to a brief description of the study.
* Save the resulting report as a PDF and include it in the repository.

The work must be reproducible. The laboratory notebook should make clear exactly how you reached the result, which tools and databases you used, and why.

There is no prescribed report length. Include enough detail to explain your reasoning.
